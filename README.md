# Skyline: Last Shift

A Godot 4 first-person 3D survival prototype foundation in an original high-rise disaster scenario.

## Run the prototype

1. Open this folder in Godot 4.3 or newer.
2. Run the project (F6/F5).
3. Use **WASD** to move, **Space** to jump, and the mouse to look around. Press **Escape** to release or recapture the mouse.

The starting scene contains a 30 × 30 m floor, a capsule player with a first-person camera, directional sunlight, and a procedural sky. There are no external asset dependencies. Touch controls and Android export will be added in a later milestone.

The project is configured for landscape orientation and Godot's mobile-compatible GL Compatibility renderer. Configure Android SDK and signing credentials locally in Godot rather than storing them in this project.
